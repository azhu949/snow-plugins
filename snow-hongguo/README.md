# 红果短剧（snow-hongguo）

Snow App 右侧面板插件，用来看红果短剧的推荐、排行、分类、搜索、详情和分集，并在面板内直接播放。插件由面板（`index.js`）和常驻后台模块（`background.mjs`，由宿主在主进程内加载）组成：面板只负责界面，后台通过非官方匿名 SDK `openhongguo` 读取公开目录数据，把视频分段解密、拼装后经本机回环 HTTP 交给面板；面板用 WebCodecs 在本机内存中解码（`VideoDecoder` 逐帧绘制到 canvas，`AudioDecoder` 解码后交给 `AudioContext` 播放）。主路径不转码；仅在用户显式选择「转码后播放」时，后台才会用 ffmpeg 生成 H.264 缓存文件。

宿主 0.5.12 起会在插件启用时自动加载 `plugin.json` 里声明的 `background` 模块（主进程内常驻，随应用启动，停用或卸载时停止），不需要手动启动；0.5.11 及更早版本不加载，只能手动运行 `server.mjs`，见「后台服务」。

## 功能

- 发现：包含「推荐 / 排行 / 分类」三个入口。推荐卡片流支持触底加载、刷新与下拉刷新。
- 排行：按作品类型与子榜切换，显示排名、热度和平台推荐标识，支持刷新和触底自动加载。
- 分类：按上游提供的剧种、题材、角色、年代、状态等条件组合筛选，支持重置、刷新和触底自动加载；具体维度随剧种变化。
- 搜索：首页展示「猜你想搜」和热搜榜，输入时提供联想；支持中文输入法、300ms 防抖和回车搜索，结果触底自动加载，最近搜索词保存在插件私有存储。
- 详情：封面、标题、简介、标签、集数、分集网格；自动读取上次观看位置并显示「继续观看 第 N 集 mm:ss」。
- 播放：自绘播放器（本机 WebCodecs 解码），支持播放/暂停、进度条拖动、音量、静音、倍速、画中画、铺满侧栏。
- 清晰度：1080p / 720p / 540p / 480p / 360p 下拉切换，切换后尽量保留当前进度，并记住偏好。所有清晰度都是同一编码（hvc1 / HEVC），切换只影响码率，不改变解码方式；实际播放在 480p 下最稳。
- 收藏追剧：详情页可加入追剧，追剧页提供收藏列表、「想看 / 在看 / 已看完」筛选；列表和详情中的状态徽标可直接点击切换，当前状态高亮。收藏独立保存，删除观看历史不会移除收藏。
- 逐集续播与历史：按集 ID 分别记录位置、时长与完成状态，选集时恢复该集进度。播放进度约每秒上报，详情页按 5 秒节流写历史；切集、暂停和关闭面板时补写最后一次进度。历史页支持删除一部剧的全部记录与清空。
- 播放偏好：倍速、音量、静音及自动连播开关持久保存，播放器与设置页同步；重新打开面板或换剧后继续沿用。
- 自动下一集：默认开启，一集播完自动切到可播放的下一集；设置中关闭后停在本集片尾，可手动下一集或重播。
- 起播与预加载：取流信息和 init 并行准备，最多三段并发读取，视频解码与音频准备并行；连播开启时在片尾预取下一集开头，切集复用同一媒体任务与缓存。
- 缓存：封面与视频分段落盘缓存；设置页可一键清理。视频保留最近 6 集，封面保留最近 300 张。
- 封面：红果返回 HEIC 时，后台优先转成 JPEG 再给面板；转换器不可用时回退原图，面板显示占位块，不影响列表与播放。
- 下拉控件：排行、分类、设置和播放器统一采用宿主风格的自绘菜单，跟随主题配色，显示选中勾号；支持键盘选择和 Esc 收起，空间不足时向上展开，避免侧栏裁切。

## 安装

### 前置条件

- Snow App 宿主（插件通过 `api.net.fetch` 与本机回环服务通信）。
- Node.js 22 或更高版本：只有源码构建、以及旧宿主（0.5.11 及更早）手动运行 `server.mjs` 时需要；0.5.12+ 的后台模块跑在宿主进程里，不依赖外部 Node。

### 从源码构建

```powershell
cd D:\ai-workspace\snow-plugins\snow-hongguo
npm install
npm run build
npm run check
npm test
```

构建会生成或刷新：

| 文件 | 说明 |
| --- | --- |
| `index.js` | 面板入口，单文件 ESM，React 由宿主注入 |
| `background.mjs` | 常驻后台模块，单文件 ESM，由宿主在主进程内加载 |
| `dist/openhongguo.wasm` | SDK 的 WebAssembly 主体，约 6.9 MB |
| `dist/wasm_exec.js` | Go wasm 运行时胶水文件 |
| `dist/package.json` | 把 `dist/` 标记为 CommonJS，保证 `wasm_exec.js` 能被 `require` |

`dist/` 三个文件必须和 `background.mjs` 一起安装，缺一个时后台会在启动或首次调用 SDK 时失败；`server.mjs` 只在旧宿主或本地调试时用到。

### 本地目录安装

1. 打开 Snow App 的「设置 → 插件」。
2. 点击「安装插件」，选择插件目录 `D:\ai-workspace\snow-plugins\snow-hongguo`。
3. 确认列表中出现「红果短剧」，且开关为启用。
4. 从右上角加号菜单的「插件」分组打开面板。宿主 0.5.12+ 会在插件启用时自动加载后台模块；旧宿主才需要按「后台服务」手动启动。

插件目录必须包含 `plugin.json`、入口文件 `index.js` 与 `background.mjs`（`server.mjs` 可选，仅旧宿主/调试用）；安装时宿主会跳过 `.git` 与 `node_modules`，目录总大小上限 128 MB。

### 通过 config 工具安装

如果使用 Snow App 的 config 工具（AI 助手或自动化脚本调用），可以直接指定源目录覆盖安装：

```text
config-set scope=plugins key="com.snow.hongguo" value={sourceDir: "D:\\ai-workspace\\snow-plugins\\snow-hongguo"}
```

检查安装状态：

```text
config-list scope=plugins
```

停用或重新启用：

```text
config-set scope=plugins key="com.snow.hongguo" value={enabled:false}
config-set scope=plugins key="com.snow.hongguo" value={enabled:true}
```

### 更新之后

- 只改了 `plugin.json`：在插件列表点「重新读取清单」。
- 改了 `index.js` / `style.css` / 语言包：重新安装覆盖，再重新打开面板。
- 改了 `background.mjs` / `dist/`：重新安装覆盖后宿主会自动停止并按新的入口重启后台模块（清单或入口文件变化也会触发重启）。旧宿主手动启动的 `server.mjs` 不会热替换，需要自己结束旧进程再启动。

## 后台服务

宿主 0.5.12 起支持 `plugin.json` 的 `background` 模块：插件启用时由 Electron 主进程加载 `background.mjs` 并调用 `start(ctx)`，随应用启动，停用、卸载或清单/入口文件变化时停止。面板通过回环 HTTP 与它通信，后台在 `127.0.0.1` 的 `37191-37200` 中挑第一个可用端口，不对外网开放。

- 用户侧不需要启动任何进程，也不需要单独安装 Node：后台模块跑在宿主进程里。
- 端口可能随重启变化，面板每次冷启动都会在区间内重新扫描，并用 `/health` 的 `pluginId` 校验身份。
- 面板「设置 → 后台状态」显示实际端口、版本、PID 与运行时长。

健康检查（需要插件的通道请求头）：

```powershell
$h = @{ "x-snow-hongguo-channel" = "panel-rpc-v1" }
foreach ($port in 37191..37200) {
  try {
    Invoke-RestMethod -Uri "http://127.0.0.1:$port/health" -Headers $h -TimeoutSec 2 |
      Select-Object pluginId, version, port, pid, uptimeMs
  } catch { }
}
```

### 旧宿主（0.5.11 及更早）

这些版本不加载 `background` 模块，面板会提示「未发现后台服务」。此时才需要在安装目录手动运行 `server.mjs`：

```powershell
$install = "$env:USERPROFILE\.snowapp\plugins\com.snow.hongguo"
Start-Process -FilePath "node" -ArgumentList "server.mjs" -WorkingDirectory $install -WindowStyle Hidden
```

手动服务会先占用 `37191`，宿主自己加载的后台模块会退到下一个空闲端口，两者共用同一份数据目录。不要同时运行，否则缓存与匿名设备档案会被两个进程同时读写。结束手动服务前先用 `Get-Process -Id <PID>` 核对进程名，不要结束宿主自身进程。


## 使用说明

### 页签

| 页签 | 内容 |
| --- | --- |
| 发现 | 推荐卡片流、作品排行榜、分类组合筛选 |
| 搜索 | 热搜、联想、输入即搜（300ms 防抖）与结果触底加载；回车立即搜索，Esc 先收起联想，再清空输入 |
| 追剧 | 收藏列表，按「想看 / 在看 / 已看完」筛选和调整状态 |
| 历史 | 按最近观看时间排序，显示集号与进度，支持删除单条与清空 |
| 设置 | 清晰度、倍速、音量、静音、自动连播、小窗偏好、缓存清理、后台状态 |

### 发现、排行与分类

- 「推荐」沿用首页卡片流。「排行」按作品类型选择子榜，榜单名称和默认榜由上游返回；目前只展示作品榜，平台推荐条目标注为「平台推荐」。
- 「分类」每个维度可选一个条件，不同维度可组合；「不限」取消该维度限制。切换剧种会重新加载对应条件并清除旧筛选，避免带入不适用的题材或年代。
- 排行和分类与推荐页一样，接近底部时自动加载下一页，首屏不足或面板扩容后自动补页；翻页保留当前条件并去掉重复作品。请求失败后暂停自动加载，可点错误提示中的重试。切换条件后从第一页开始，旧请求的结果不会混入新列表。
- 打开详情后返回，或在发现页内切换入口，会保留已加载结果和当前选择；重新打开面板后恢复默认。点击剧目可进入详情、选集播放或加入追剧。

### 搜索

- 进入搜索页时加载「猜你想搜」与热搜榜，数据短期缓存；点击剧目打开详情，点击话题按文字搜索。无热搜数据时仍可正常输入搜索。
- 联想最多显示 6 项，支持上下方向键、回车和 Esc；中文输入法选字期间不发送搜索请求。联想失败不影响普通搜索，快速换词或清空时忽略旧响应。
- 结果接近底部时自动翻页，首屏不足时补页；保留关键词、去重并阻止循环游标。分页失败后保留已有结果，重试当前页；游标过期则重新搜索第一页。打开详情或切换页签时暂停自动翻页，返回后保留结果。

### 起播与下一集预加载

- 起播同时准备流信息与 init，最多三个分段并发读取后按顺序解析，视频解码与音频准备同时进行，不再固定等待 350ms。仍需获取完整分段以支持保调音频和任意位置跳转，实际等待时间取决于网络与设备。
- 自动连播开启且本集播放稳定时，播放达到 60%、按当前倍速预计剩余不超过 30 秒才预取下一集；只处理紧邻且可播放的一集，按最多 4MB 的源数据准备开头分段，不提前解码音视频。
- 暂停、缓冲、换剧、换清晰度、隐藏页面或关闭播放器时取消预取；关闭自动连播也会取消。后台最多保留两个预取租约，60 秒未接管自动停止；预取失败不打断当前播放，自动重试有次数限制。
- 正式播放接管已预取任务后，旧租约的取消不会中断播放；同一实际清晰度共用下载任务，缓存清理会先停止预取及在途下载。

### 收藏追剧

- 在详情页点「加入追剧」。未观看的剧默认归为「想看」，有进度的剧归为「在看」；开始观看后，已收藏的「想看」会自动转为「在看」。
- 在详情或追剧页直接点击「想看 / 在看 / 已看完」徽标调整状态，当前状态以颜色和边框高亮；保存期间暂停切换，避免重复提交。「已看完」由你手动设置，重新播放不会自动把它改回「在看」。
- 追剧页只展示已收藏的剧，收藏条目显示最近观看的集数和时间；观看历史统一在历史页查看。
- 点击「已收藏」或列表中的「取消收藏」移除收藏；已有观看历史保留。最多收藏 500 部剧。

### 详情页

- 顶部是播放器；没有分集或分集加载失败时播放器不挂载。
- 「继续观看」按钮会跳到上次的集号与位置；有历史时按钮下方显示「第 N 集 mm:ss」。
- 分集网格区分未看、部分观看（显示已看到的时间）和已看完（勾号）；当前集高亮，不可播放的集为禁用状态。只有收到播放结束事件才标为已看完，跳到第 20 集不会把前 19 集标为已看。
- 每集单独续播；已播完且停在片尾的集重新选择时从头播放，重看中途退出仍可续播。集 ID 用来关联进度，目录调整顺序不会把进度套给另一集。
- 简介超过 140 字时提供展开/收起。

### 播放器控件

| 控件 | 行为 |
| --- | --- |
| 播放 / 暂停 | 点击画面或按钮；自动播放被宿主拦截时显示大播放按钮与提示 |
| 进度条 | 显示已播与已缓冲区间；悬停显示时间气泡；按住拖动可 seek |
| 时间 | 当前时间 / 总时长 |
| 下一集 | 最后一集时禁用；键盘 `N` 也可切下一集 |
| 音量 | 滑杆与静音按钮；音量拉到 0 自动静音，音量与静音状态自动保存 |
| 倍速 | 0.75x 到 3x，共 8 档；本机解码和兼容播放均支持；切集、换剧、重开面板、切清晰度、回退及重播保留所选速度 |
| 清晰度 | 1080p / 720p / 540p / 480p / 360p，切换后写入偏好 |
| 画中画 | 浏览器不支持时隐藏按钮 |
| 铺满侧栏 | 把播放器临时移到页面顶层并铺满视口；再次点击、双击画面或 Esc 退出 |

### 快捷键

焦点需要在播放器内（先点一下画面）。输入框、下拉框内的按键不会被拦截；焦点在按钮上时空格/回车交给按钮本身。

| 按键 | 行为 |
| --- | --- |
| `空格` / `K` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `↑` / `↓` | 音量 +5% / -5% |
| `M` | 静音切换 |
| `F` | 进入 / 退出铺满 |
| `Esc` | 退出铺满 |
| `N` | 下一集 |
| `<` / `>` | 倍速减 / 加 |

### 缓存清理

「设置 → 缓存 → 清理缓存」需要点两次：第一次进入确认态，4 秒内再点一次才执行。清理会先停止正在下载的媒体任务，再删除 `video/` 与 `covers/`；正在播放的播放器会中断，需要重新点播放。清理成功后提示删除数量。

## 数据与隐私

### 联网范围

插件在 `plugin.json` 中只声明了 `network` 一个隐私域，没有声明 `filesystem`、`conversations`、`projects`、`terminal` 等任何宿主数据域。

- 后台模块（`background.mjs`，跑在宿主主进程里）使用非官方匿名 SDK `openhongguo` 访问红果短剧的公开目录与播放接口（`fqnovel.com`）。
- 封面按白名单抓取图片 CDN（`fqnovelpic.com`、`fqnovel.com`、`byteimg.com` 等），拒绝内网地址、非 https 地址与白名单外域名。
- 面板不直接访问外网；它只调用 `http://127.0.0.1:37191-37200` 上的本插件后台模块，并带自定义通道头。
- 后台模块只绑定 `127.0.0.1`，拒绝带 `Origin` 的请求；它不是公网服务，也不是可分享的播放直链。
- 播放时的 fMP4 分段（init + segment）由后台经回环 HTTP 交给面板，面板在本机内存中用 WebCodecs 解码显示，不挂到媒体元素、不外发。用户显式选择「转码后播放」时，转码产物会写入 `video/<集>/<清晰度>-h264/`，随后分块读回面板内存再交给 `<video>`。

### 本地数据

| 位置 | 内容 | 清理方式 |
| --- | --- | --- |
| `<userData>/plugin-data/com.snow.hongguo/anonymous.json` | SDK 生成的匿名设备档案 | 删除后下次调用会重新注册匿名设备 |
| `<userData>/plugin-data/com.snow.hongguo/covers/` | 封面缓存（HEIC 转码后为 `.jpg`） | 设置页清理缓存 |
| `<userData>/plugin-data/com.snow.hongguo/video/` | 视频分段、初始化段与解析信息；显式转码时另有 `video/<集>/<清晰度>-h264/`（`h264.mp4`、`meta.json`，转码期间临时存在 `source.mp4`） | 设置页清理缓存 |
| 宿主插件私有存储（`app_plugin_values` 表） | 逐集观看历史、追剧收藏、播放与小窗偏好、最近搜索词 | 历史页删除/清空；追剧页取消收藏；设置页调整偏好；搜索页清空最近搜索 |

`<userData>` 是 Electron 的用户数据目录，常见位置：

- Windows：`%APPDATA%\Snow App\plugin-data\com.snow.hongguo\`（打包版；源码运行时为 `%APPDATA%\snow-app\...`）
- macOS：`~/Library/Application Support/Snow App/plugin-data/com.snow.hongguo/`（打包版；源码运行时为 `.../snow-app/...`）
- Linux：`${XDG_CONFIG_HOME:-~/.config}/Snow App/plugin-data/com.snow.hongguo/`（打包版；源码运行时为 `.../snow-app/...`）

缓存策略：

- 视频按「集 + 清晰度」目录保存，最多保留最近 6 个任务目录；启动时清理一次，运行中每 10 分钟清理一次。
- 封面最多保留 300 张，按修改时间淘汰；同一封面 URL 的签名参数变化不会产生新缓存键。
- 分类条件面板按剧种在后台内存缓存 10 分钟，最多 20 份，同时发起的相同请求合并；不写入磁盘。
- 排行和分类的 SDK 分页游标保留在后台，面板只传短标识，避免连续浏览时请求地址过长。映射在内存中保留 30 分钟、最多 200 条；过期、淘汰或后台重启后，点击重试会从第一页重新加载当前条件。
- 启动时清理残留的 `*.part` 临时文件。

### 不上传数据

插件没有账号体系，不读取宿主会话、项目、终端、文件或任何应用数据，也不会上传观看历史、搜索词或设备档案。唯一对外发送的是访问红果公开接口所需的请求参数，以及 SDK 生成的匿名设备标识。

### 封面转码

红果封面常见为 HEIC，Chromium 不能直接解码。后台按平台尝试：

1. macOS：`/usr/bin/sips`
2. PATH 中的 `ffmpeg`
3. Windows：系统自带的 WPF/WIC（通过 PowerShell 调用）

三者都不可用或转换失败时，接口返回原图，面板显示占位块。`ffmpeg` 只是可选的封面转码器，不是视频播放或封面的硬依赖；没有它也能正常浏览和播放。转码结果会写成 `.jpg` 覆盖同一封面的缓存。封面转换会在系统临时目录创建 `hongguo-cover-*` 工作目录（`in.heic`、`out.jpg`、`wic-cover.ps1`），结束后递归删除；Windows 上的 PowerShell 以 `-ExecutionPolicy Bypass -File` 执行 WIC 解码脚本。

## 已知限制

1. **HEVC 编码支持取决于平台与 GPU。** `/playback` 实测 5 档清晰度全部是 `bytevc1`（字节系 HEVC），没有 H.264 档位；其中 720p 与 360p 解析出的编码串都是 `hvc1.1.6.L186,mp4a.40.2`。主路径用 WebCodecs 的 `VideoDecoder` / `AudioDecoder` 在本机解码，能否播放取决于宿主 Chromium 是否提供该编码的解码能力：不支持时播放器显示「无法播放该编码」，不会白屏。本机解码不可用时可以尝试 MSE，或在降级面板里显式选择「转码后播放」（后台 ffmpeg 转 H.264）；宿主 CSP 没有 media-src，媒体元素加载 blob: 也可能被拒绝，因此这两种回退不保证成功。切换 360p/480p 不会改变编码，真正可用的兜底是「下载本集」后用支持 HEVC 的外部播放器（如 VLC、PotPlayer）打开，或复制本机媒体地址做诊断。
2. **匿名设备频率限制。** 匿名接口在高频请求时可能返回 `ANONYMOUS_LIMITED` 或空响应；后台会自动重置匿名设备并重试，仍失败时需要等待一段时间再试。短时间内反复刷新列表、频繁切清晰度更容易触发。
3. **接口非官方，可能失效。** 上游是红果/字节的私有接口，字段、签名、域名或风控策略变化都可能导致列表、分集或播放不可用；这类问题需要更新 `openhongguo` 或适配代码，不是配置问题。
4. **超长剧集会被截断。** 分集接口最多请求 8 页、最多 2000 条，且响应体限制 64 KB；超出时详情页显示截断提示，播放器只能访问已返回的分集。
5. **本机播放先读取整集。** 主播放路径最多三个分段并发读取、按序解析，再并行准备音画；首播和切清晰度仍需等待完整样本，加载完成后跳转无需重新取流。片尾的下一集预加载只提前缓存开头，不能保证无缝切集。
6. **历史与收藏保存在本机。** 历史列表保留最近 100 部剧，每部最多 2000 条分集记录。升级前的旧历史只有最后一集的位置，只迁移这一集，不补造之前各集的完成状态。收藏最多 500 部，与历史独立；不跨设备同步。
7. **不支持字幕、音轨选择、逐帧、循环播放。** 当前只有一条音视频轨。
8. **`复制播放地址` 不是公网直链。** 后台刻意不向面板暴露 CDN 直链与内容密钥，复制的是 `http://127.0.0.1:<port>/stream/info?...`，需要插件的通道请求头才能访问，主要用于诊断。
9. **铺满区域依赖 `:has()`。** 不支持 `:has()` 的渲染层会退回 16:9 占位框，画面较小但不影响播放。
10. **端口区间固定。** 后台在 `127.0.0.1:37191-37200` 中找第一个可用端口；区间被其他程序占满时后台启动失败，面板会提示找不到后台服务。
11. **后台模块随宿主启动（需 0.5.12+）。** 0.5.12 起由宿主在主进程内加载 `background.mjs`；更早的版本不加载，只能按「后台服务」手动执行 `node server.mjs`。后台起不来时面板会提示「未发现后台服务」，处理见故障排查。
12. **倍速保留音调，但首次切档需要处理音频。** 本机解码使用 SoundTouchJS 的 WSOLA 时间拉伸处理整集音频，只改变语速、不直接提高音频采样播放速度；1x 使用原音频。处理在独立 Worker 中完成，准备期间冻结音画，完成后从原位置继续，缓存只保留一个非 1x 档位。画面仍按音频输出时钟选帧，解码跟不上时暂停音频并冻结进度，待画面追上后继续。高倍速仍可能有时间拉伸带来的音色细节变化；倍速写入播放偏好，下次打开沿用。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 面板一直显示「未发现本插件后台服务」 | 确认插件为启用状态、宿主为 0.5.12+（后台模块随宿主加载）；在插件列表禁用再启用可触发重启；用上面的健康检查逐个端口探 `/health`；仍无响应时检查 37191-37200 是否被其他程序占满 |
| 打开面板就提示插件已禁用 | 在插件列表重新启用，然后重新打开面板 |
| 列表/搜索报限流 | 等待提示的秒数后重试；避免连续快速刷新 |
| 播放器显示「无法播放该编码」 | 平台不支持 HEVC；下载本集后用支持 HEVC 的播放器打开，或在支持硬件解码的环境运行宿主 |
| 封面全是占位块 | 封面可能是 HEIC 且本机没有可用转换器；macOS 可用 `sips`，Windows 需要 HEIF 图像扩展，Linux 可安装 `ffmpeg` 后重启后台 |
| 播放卡住后出现重试按钮 | 网络中断或分段请求失败；点重试，或切换清晰度重新建立连接 |
| 清理缓存后当前播放中断 | 清理会停止媒体任务，重新点播放即可 |

后台模块的日志写入宿主日志，检索 `hongguo` 可看到启动、缓存、SDK 与媒体管道输出；旧宿主手动运行 `node server.mjs` 时会打印到启动它的窗口。
